Testprojekt für die FHIR-Spezifikation des Therapie-Datensatzes (Operation, Strahlentherapie und systemische Therapie).

Änderungen an den Profilen und weiteren Artefakten sollen grundsätzlich zuerst im zugehörigen GitHub-Repository vorgenommen und anschließend in Simplifier übernommen bzw. synchronisiert werden. Dadurch wird sichergestellt, dass GitHub als zentrale Quelle dient und keine Inkonsistenzen zwischen Repository und Simplifier-Projekt entstehen.
